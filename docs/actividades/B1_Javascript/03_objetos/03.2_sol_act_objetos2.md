# Actividad 1. Crear y modificar un objeto (15 minutos)

## Enunciado

Crea un objeto llamado `producto` con estas propiedades:

- `nombre`: `"Teclado"`
- `precio`: `29.99`
- `disponible`: `true`

Realiza las siguientes operaciones:

1. Muestra el objeto completo por consola.
2. Muestra el nombre y el precio usando la notación de punto.
3. Cambia el precio a `24.99`.
4. Añade una propiedad `marca` con el valor `"Logitech"`.
5. Guarda el nombre de una propiedad en una variable y utiliza la notación de corchetes para consultar su valor.
6. Muestra el objeto final por consola.

### Preguntas

a. ¿Qué diferencia hay entre la notación de punto y la notación de corchetes?  
b. ¿Cuándo es necesario utilizar la notación de corchetes?  
c. ¿Se puede añadir una propiedad a un objeto después de crearlo?

## Solución

```javascript
const producto = {
    nombre: "Teclado",
    precio: 29.99,
    disponible: true
};

console.log(producto);

console.log(producto.nombre);
console.log(producto.precio);

producto.precio = 24.99;
producto.marca = "Logitech";

const propiedad = "disponible";
console.log(producto[propiedad]);

console.log(producto);
```

### Respuestas a las preguntas

**a. Diferencia entre notación de punto y de corchetes**

- Con la notación de punto se escribe directamente el nombre de la propiedad: `producto.nombre`.
- Con la notación de corchetes se escribe una expresión entre corchetes: `producto["nombre"]` o `producto[propiedad]`.

**b. ¿Cuándo es necesaria la notación de corchetes?**

Cuando el nombre de la propiedad se guarda en una variable o se calcula dinámicamente. Por ejemplo:

```javascript
const propiedad = "precio";
console.log(producto[propiedad]); // 24.99
```

`producto.propiedad` buscaría una propiedad llamada literalmente `propiedad`, no la propiedad cuyo nombre contiene la variable.

**c. ¿Se puede añadir una propiedad después de crear el objeto?**

Sí. Se puede asignar un valor a una propiedad nueva:

```javascript
producto.marca = "Logitech";
```

# Actividad 2. Propiedades dinámicas y recorrido de objetos (15 minutos)

## Enunciado

Crea un objeto `alumno` con las propiedades `nombre`, `curso` y `nota`. Utiliza los valores que quieras.

1. Guarda el nombre de una nueva propiedad en una variable llamada `nuevaPropiedad`.
2. Utiliza esa variable para añadir al objeto una propiedad `grupo` con el valor `"A"`.
3. Comprueba si el objeto tiene la propiedad `nombre`.
4. Comprueba si el objeto tiene la propiedad `edad`.
5. Recorre las propiedades del objeto con un bucle `for...in` y muestra por consola el nombre y el valor de cada propiedad.

### Preguntas

a. ¿Para qué sirve el operador `in`?  
b. ¿Qué devuelve `in` en las comprobaciones de `nombre` y `edad`?  
c. ¿Qué información proporciona la variable de control de `for...in`?  
d. ¿Por qué puede ser conveniente comprobar `Object.hasOwn(alumno, clave)` dentro del bucle?

## Solución

```javascript
const alumno = {
    nombre: "Aina",
    curso: "2.º DAW",
    nota: 8.5
};

const nuevaPropiedad = "grupo";
alumno[nuevaPropiedad] = "A";

console.log("nombre" in alumno); // true
console.log("edad" in alumno);   // false

for (const clave in alumno) {
    if (Object.hasOwn(alumno, clave)) {
        console.log(`${clave}: ${alumno[clave]}`);
    }
}
```

### Respuestas a las preguntas

**a. ¿Para qué sirve `in`?**

Comprueba si una propiedad existe en un objeto o en su cadena de prototipos. El resultado es un booleano: `true` o `false`.

**b. Resultados de las comprobaciones**

- `"nombre" in alumno` devuelve `true`, porque la propiedad existe.
- `"edad" in alumno` devuelve `false`, porque no se ha definido esa propiedad ni se encuentra en la cadena de prototipos.

**c. ¿Qué proporciona `clave` en `for...in`?**

En cada iteración contiene el nombre de una propiedad enumerable que se está recorriendo. Para obtener su valor se utiliza `alumno[clave]`.

**d. ¿Para qué sirve `Object.hasOwn()`?**

Permite comprobar que la propiedad pertenece directamente al objeto y no se ha heredado de su prototipo. Esto resulta útil cuando solo queremos procesar propiedades propias.

# Actividad 3. Referencias, copias y objetos anidados (20 minutos)

## Enunciado

Crea el siguiente objeto:

```javascript
const original = {
    nombre: "Ordenador",
    precio: 750,
    caracteristicas: {
        ram: "16 GB",
        almacenamiento: "1 TB"
    }
};
```

Realiza estas operaciones y observa los resultados:

1. Asigna `original` a una variable llamada `referencia` y cambia desde ella el precio a `700`.
2. Crea una copia superficial usando `Object.assign({}, original)`. Cambia el precio de la copia a `680`.
3. Cambia la memoria RAM de la copia superficial a `"32 GB"`.
4. Crea una copia profunda con `structuredClone(original)`. Cambia la memoria RAM de esta copia a `"64 GB"`.
5. Muestra por consola los valores relevantes después de cada operación.

### Preguntas

a. ¿Por qué cambiar el precio a través de `referencia` también modifica `original`?  
b. ¿Qué diferencia hay entre una referencia y una copia superficial?  
c. ¿Por qué cambiar `copiaSuperficial.caracteristicas.ram` también afecta al objeto original?  
d. ¿Qué ventaja ofrece `structuredClone()` en este ejemplo?  
e. ¿Se puede utilizar `structuredClone()` con cualquier tipo de valor?

## Solución

```javascript
const original = {
    nombre: "Ordenador",
    precio: 750,
    caracteristicas: {
        ram: "16 GB",
        almacenamiento: "1 TB"
    }
};

// referencia y original apuntan al mismo objeto
const referencia = original;
referencia.precio = 700;

console.log(original.precio); // 700

// Copia superficial
const copiaSuperficial = Object.assign({}, original);
copiaSuperficial.precio = 680;

console.log(original.precio);         // 700
console.log(copiaSuperficial.precio); // 680

// El objeto anidado sigue compartido
copiaSuperficial.caracteristicas.ram = "32 GB";
console.log(original.caracteristicas.ram); // "32 GB"

// Copia profunda
const copiaProfunda = structuredClone(original);
copiaProfunda.caracteristicas.ram = "64 GB";

console.log(original.caracteristicas.ram);    // "32 GB"
console.log(copiaProfunda.caracteristicas.ram); // "64 GB"
```

### Respuestas a las preguntas

**a. ¿Por qué cambia también `original`?**

Porque `referencia` no contiene una copia independiente del objeto: ambas variables apuntan al mismo objeto en memoria. Por eso, modificarlo mediante una variable se observa al consultarlo mediante la otra.

**b. Diferencia entre referencia y copia superficial**

Una asignación como `const referencia = original` copia la referencia al objeto. `Object.assign({}, original)` crea un objeto nuevo y copia en él las propiedades propias enumerables de primer nivel. Sin embargo, los valores que son otros objetos se copian también como referencias.

**c. ¿Por qué se modifica la RAM del original?**

Porque `original.caracteristicas` y `copiaSuperficial.caracteristicas` apuntan al mismo objeto anidado. La copia es superficial, no profunda.

**d. Ventaja de `structuredClone()`**

Crea una copia profunda de los datos compatibles, incluidos los objetos anidados. Por eso, cambiar la RAM de `copiaProfunda` no cambia la RAM de `original`.

**e. ¿Funciona con cualquier valor?**

No. `structuredClone()` admite muchos tipos de datos y referencias circulares, pero no clona todos los valores posibles; por ejemplo, las funciones no son compatibles con la clonación estructurada.

# Actividad 4. Métodos y `this` (20 minutos)

## Enunciado

Crea un objeto `cuenta` con estas propiedades:

- `titular`: `"Marcos"`
- `saldo`: `500`

Añade los métodos siguientes:

1. `ingresar(cantidad)`: suma la cantidad al saldo si es mayor que cero. Debe devolver `true` si la operación se realiza y `false` en caso contrario.
2. `retirar(cantidad)`: resta la cantidad si es mayor que cero y no supera el saldo disponible. Debe devolver `true` si se realiza la operación y `false` si no.
3. `consultarSaldo()`: devuelve el saldo actual.

Prueba los métodos ingresando `150`, retirando `200`, intentando retirar `1000` e intentando ingresar `-10`.

### Ampliación

Crea una segunda cuenta y escribe una función `transferir(origen, destino, cantidad)` que transfiera dinero si la cantidad es positiva y hay saldo suficiente.

### Preguntas

a. ¿Qué es un método de un objeto?  
b. ¿Qué valor tiene `this` cuando se llama a `cuenta.ingresar(150)`?  
c. ¿Por qué es preferible usar `this.saldo` en vez de escribir directamente el nombre de una variable externa?  
d. ¿Qué debería ocurrir si se intenta retirar una cantidad superior al saldo?

## Solución

```javascript
const cuenta = {
    titular: "Marcos",
    saldo: 500,

    ingresar(cantidad) {
        if (cantidad > 0) {
            this.saldo += cantidad;
            return true;
        }

        return false;
    },

    retirar(cantidad) {
        if (cantidad > 0 && cantidad <= this.saldo) {
            this.saldo -= cantidad;
            return true;
        }

        return false;
    },

    consultarSaldo() {
        return this.saldo;
    }
};

console.log(cuenta.consultarSaldo()); // 500

cuenta.ingresar(150);
console.log(cuenta.consultarSaldo()); // 650

cuenta.retirar(200);
console.log(cuenta.consultarSaldo()); // 450

console.log(cuenta.retirar(1000)); // false
console.log(cuenta.ingresar(-10)); // false
```

### Solución de la ampliación

```javascript
const cuentaDestino = {
    titular: "Lucía",
    saldo: 100
};

function transferir(origen, destino, cantidad) {
    if (cantidad > 0 && cantidad <= origen.saldo) {
        origen.saldo -= cantidad;
        destino.saldo += cantidad;
        return true;
    }

    return false;
}

console.log(transferir(cuenta, cuentaDestino, 50)); // true
console.log(cuenta.saldo);        // 400
console.log(cuentaDestino.saldo); // 150
```

### Respuestas a las preguntas

**a. ¿Qué es un método?**

Es una función que se guarda como propiedad de un objeto y representa una acción que ese objeto puede realizar.

**b. ¿Qué valor tiene `this`?**

En la llamada `cuenta.ingresar(150)`, `this` hace referencia a `cuenta`, porque es el objeto situado antes del punto en la llamada al método.

**c. ¿Por qué utilizar `this.saldo`?**

Porque hace referencia a la propiedad del objeto que está ejecutando el método. Así el método puede funcionar con distintas cuentas sin depender de una variable externa concreta.

**d. ¿Qué pasa si se retira más dinero del disponible?**

La operación debe rechazarse: el saldo no cambia y el método devuelve `false`.

# Actividad 5. Constructores, instancias y prototipos (25 minutos)

## Enunciado

Crea una función constructora llamada `Producto` que reciba `nombre` y `precio` y los almacene en el nuevo objeto mediante `this`.

1. Crea el método `mostrarInformacion()` en `Producto.prototype`. Debe devolver el nombre y el precio con dos decimales.
2. Crea el método `aplicarDescuento(porcentaje)` en el prototipo. Si el porcentaje está entre 0 y 100, debe actualizar el precio.
3. Crea dos productos usando `new Producto(...)`.
4. Muestra la información de ambos productos.
5. Aplica un descuento del 20 % al primer producto y vuelve a mostrar su información.
6. Comprueba si ambos productos son instancias de `Producto`.
7. Comprueba si `mostrarInformacion` es una propiedad propia del primer producto.

### Preguntas

a. ¿Para qué sirve una función constructora?  
b. ¿Qué hace el operador `new`?  
c. ¿Qué diferencia hay entre las propiedades propias de una instancia y los métodos guardados en el prototipo?  
d. ¿Qué comprueba `instanceof`?  
e. ¿Por qué se suelen definir métodos compartidos en el prototipo?

## Solución

```javascript
function Producto(nombre, precio) {
    this.nombre = nombre;
    this.precio = precio;
}

Producto.prototype.mostrarInformacion = function () {
    return `${this.nombre}: ${this.precio.toFixed(2)} €`;
};

Producto.prototype.aplicarDescuento = function (porcentaje) {
    if (porcentaje >= 0 && porcentaje <= 100) {
        this.precio *= 1 - porcentaje / 100;
    }
};

const producto1 = new Producto("Ratón", 25);
const producto2 = new Producto("Monitor", 180);

console.log(producto1.mostrarInformacion()); // Ratón: 25.00 €
console.log(producto2.mostrarInformacion()); // Monitor: 180.00 €

producto1.aplicarDescuento(20);

console.log(producto1.mostrarInformacion()); // Ratón: 20.00 €

console.log(producto1 instanceof Producto); // true
console.log(producto2 instanceof Producto); // true

console.log(
    Object.getPrototypeOf(producto1) === Producto.prototype
); // true

console.log(Object.hasOwn(producto1, "nombre")); // true
console.log(Object.hasOwn(producto1, "mostrarInformacion")); // false
```

### Respuestas a las preguntas

**a. ¿Para qué sirve una función constructora?**

Permite crear varios objetos con una estructura inicial similar, asignando a cada instancia sus propios datos.

**b. ¿Qué hace `new`?**

Crea un nuevo objeto, lo vincula al prototipo de la función constructora, ejecuta la función con `this` asociado al nuevo objeto y devuelve ese objeto (salvo el caso especial de que el constructor devuelva explícitamente otro objeto).

**c. Diferencia entre propiedades propias y métodos del prototipo**

`nombre` y `precio` son propiedades propias de cada instancia. Los métodos definidos en `Producto.prototype` se comparten a través de la cadena de prototipos y no se copian como propiedades propias en cada instancia.

**d. ¿Qué comprueba `instanceof`?**

Comprueba si el prototipo de la función constructora aparece en la cadena de prototipos del objeto. En este caso, las dos expresiones devuelven `true`.

**e. ¿Por qué compartir métodos en el prototipo?**

Para que las instancias puedan reutilizar los mismos métodos, en lugar de crear una copia de cada función en cada objeto.

# Actividad 6. Encadenamiento opcional y reto final (25 minutos)

## Parte A. Encadenamiento opcional

### Enunciado

Analiza este objeto y completa el código para consultar de forma segura propiedades y métodos que podrían no existir:

```javascript
const usuario = {
    nombre: "Nora",
    direccion: {
        ciudad: "Castellón"
    },
    saludar() {
        return `Hola, soy ${this.nombre}`;
    }
};
```

Escribe expresiones que permitan:

1. Consultar la ciudad.
2. Consultar un posible teléfono dentro de `contacto`.
3. Consultar un posible código postal dentro de `direccion`.
4. Llamar al método `saludar` solo si existe.
5. Intentar llamar a un método `despedir` solo si existe.

### Preguntas

a. ¿Qué problema evita el operador `?.`?  
b. ¿Qué valor devuelve `usuario.contacto?.telefono` si `contacto` no existe?  
c. ¿El encadenamiento opcional impide cualquier error? Explica por qué.

## Solución de la parte A

```javascript
console.log(usuario.direccion?.ciudad); // "Castellón"
console.log(usuario.contacto?.telefono); // undefined
console.log(usuario.direccion?.codigoPostal); // undefined
console.log(usuario.saludar?.()); // "Hola, soy Nora"
console.log(usuario.despedir?.()); // undefined
```

### Respuestas a las preguntas

**a. ¿Qué problema evita `?.`?**

Evita que el acceso o la llamada continúe cuando el valor situado a la izquierda del operador es `null` o `undefined`. En esos casos, la expresión devuelve `undefined`.

**b. ¿Qué devuelve `usuario.contacto?.telefono`?**

Devuelve `undefined`, porque `usuario.contacto` no existe y, por tanto, su valor es `undefined`.

**c. ¿Evita cualquier error?**

No. El operador solo trata el caso de `null` o `undefined`. Si la propiedad existe pero contiene un valor que no es una función, una llamada opcional como `obj.metodo?.()` puede seguir produciendo un `TypeError`.

## Parte B. Reto final: gestión de productos

### Enunciado

Implementa un objeto llamado `catalogo` con:

- Una propiedad `nombre` con el valor `"Tienda DAW"`.
- Un array `productos` con al menos tres productos. Cada producto debe tener `id`, `nombre`, `precio` y `disponible`.
- Un método `listarProductos()` que muestre el nombre y el precio de todos los productos.
- Un método `buscarProducto(id)` que devuelva el producto cuyo identificador coincida con el recibido.
- Un método `cambiarPrecio(id, nuevoPrecio)` que cambie el precio si el producto existe y el nuevo precio no es negativo. Debe devolver `true` si cambia el precio y `false` si no puede hacerlo.
- Un método `listarDisponibles()` que devuelva un array con los productos disponibles.

Prueba todos los métodos, incluyendo la búsqueda de un identificador inexistente y el intento de cambiar un precio a un valor negativo. Utiliza el encadenamiento opcional cuando consultes propiedades de un producto que podría no haberse encontrado.

### Solución

```javascript
const catalogo = {
    nombre: "Tienda DAW",

    productos: [
        {
            id: 1,
            nombre: "Teclado",
            precio: 30,
            disponible: true
        },
        {
            id: 2,
            nombre: "Ratón",
            precio: 15,
            disponible: false
        },
        {
            id: 3,
            nombre: "Monitor",
            precio: 180,
            disponible: true
        }
    ],

    listarProductos() {
        this.productos.forEach(producto => {
            console.log(`${producto.nombre}: ${producto.precio} €`);
        });
    },

    buscarProducto(id) {
        return this.productos.find(producto => producto.id === id);
    },

    cambiarPrecio(id, nuevoPrecio) {
        const producto = this.buscarProducto(id);

        if (producto && nuevoPrecio >= 0) {
            producto.precio = nuevoPrecio;
            return true;
        }

        return false;
    },

    listarDisponibles() {
        return this.productos.filter(producto => producto.disponible);
    }
};

// 1. Listar todos los productos
catalogo.listarProductos();

// 2. Buscar un producto existente
const encontrado = catalogo.buscarProducto(2);
console.log(encontrado?.nombre); // "Ratón"

// 3. Buscar un producto inexistente
const inexistente = catalogo.buscarProducto(99);
console.log(inexistente?.nombre); // undefined

// 4. Cambiar el precio de un producto existente
console.log(catalogo.cambiarPrecio(1, 27.5)); // true
console.log(catalogo.buscarProducto(1)?.precio); // 27.5

// 5. Intentar cambiar un producto inexistente
console.log(catalogo.cambiarPrecio(99, 10)); // false

// 6. Intentar establecer un precio negativo
console.log(catalogo.cambiarPrecio(1, -5)); // false
console.log(catalogo.buscarProducto(1)?.precio); // 27.5

// 7. Mostrar solo los productos disponibles
console.log(catalogo.listarDisponibles());
```

### Respuestas y comprobaciones del reto

**1. ¿Qué muestra `listarProductos()`?**

Muestra los tres productos con su nombre y precio: Teclado (30 €), Ratón (15 €) y Monitor (180 €), antes de modificar el precio del teclado.

**2. ¿Qué devuelve `buscarProducto(2)`?**

Devuelve el objeto correspondiente al Ratón. Si se ejecuta `buscarProducto(99)`, devuelve `undefined`, porque no hay ningún producto con ese identificador.

**3. ¿Qué devuelve `cambiarPrecio(1, 27.5)`?**

Devuelve `true` y actualiza el precio del teclado a `27.5`.

**4. ¿Qué ocurre con `cambiarPrecio(99, 10)`?**

Devuelve `false`, porque no existe un producto con identificador `99`.

**5. ¿Qué ocurre con `cambiarPrecio(1, -5)`?**

Devuelve `false` y mantiene el precio anterior, porque el método rechaza precios negativos.

**6. ¿Qué devuelve `listarDisponibles()`?**

Devuelve un array con los productos cuyo atributo `disponible` es `true`: el Teclado y el Monitor.

**7. ¿Por qué se utiliza `encontrado?.nombre`?**

Porque `buscarProducto()` puede devolver `undefined`. El encadenamiento opcional permite consultar `nombre` sin provocar un error cuando no se encuentra el producto.

# Resumen para corregir

| Concepto | Respuesta clave |
|---|---|
| Notación de punto | Accede a una propiedad conocida: `objeto.nombre`. |
| Notación de corchetes | Permite usar cadenas o expresiones: `objeto[clave]`. |
| Operador `in` | Comprueba si una propiedad existe en el objeto o en su cadena de prototipos. |
| `for...in` | Recorre nombres de propiedades enumerables. |
| Referencias | Dos variables pueden apuntar al mismo objeto. |
| `Object.assign()` | Copia propiedades propias enumerables de primer nivel; no clona profundamente los objetos anidados. |
| `structuredClone()` | Clona profundamente datos compatibles con la clonación estructurada. |
| Método | Función almacenada como propiedad de un objeto. |
| `this` | En una llamada `objeto.metodo()`, hace referencia al objeto que realiza la llamada. |
| Constructor y `new` | Permiten crear instancias inicializadas con una estructura común. |
| `prototype` | Permite compartir propiedades y métodos mediante la cadena de prototipos. |
| `instanceof` | Comprueba si un prototipo aparece en la cadena de prototipos de un objeto. |
| Encadenamiento opcional `?.` | Evita continuar el acceso o la llamada si el valor anterior es `null` o `undefined`. |
